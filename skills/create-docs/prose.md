# 行文

模式 A 写简介、或用户要求按行文重写时读本文件。也适用于 Accessibility 正文和 `docs/get-started/` 这类说明页。表的说明列保持短说明。

中文说明学 [Naive UI 介绍页](https://www.naiveui.com/zh-CN/os-theme/docs/introduction)：短、白、像作者在说话。

- 标题说事实。用「UnoCSS」「还早」，不用「UnoCSS 收得住」「别再跟库拔河」。
- 句子短。第一人称可以有（「我尽力了」）。
- 指用户的代码用「项目」。
- 少比喻。价值一句话说完。
- 「顺便一提」一类旁白整页至多一次，用在真正容易踩坑的地方。

对照：

| 写成                                                           | 而不是                                               |
| -------------------------------------------------------------- | ---------------------------------------------------- |
| 一套 Vue 组件，用 Reka UI 和 UnoCSS 做的。源码会写进你的项目。 | 可复用的 Vue 组件 registry，基于 Reka UI 与 UnoCSS。 |
| 我尽力了，但现在别用在生产上。                                 | 目前仍处于早期开发，不建议用于生产环境。             |
| 源码会写进你的项目。                                           | 组件以源码写入你的项目，而不是作为运行时包引入。     |
| 默认路径是                                                     | 默认路径与本仓库一致                                 |

腔调对照：`docs/get-started/index.md`、`docs/.vitepress/theme/components/HomePage.vue` 里的 `features` 与导语。
